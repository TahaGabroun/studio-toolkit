# Specialist graphics mechanisms

Preserve four useful upstream modes within one native skill:

- Diagram / typography: choose one causal mechanism, progressively build connections, keep one clear focal target and readable holds. Do not fill a quiet beat with narration restated as a card.
- Continuous camera: one world roughly 2–2.5 view widths, shared focus and zoom keys, hold → travel → action → settle. Keep focus, cursor, annotations and objects in the same coordinate system. Log-space zoom prevents uneven speed. Avoid camera travel while essential text is being read.
- Terminal insert: actual or explicitly illustrative command → progress → resulting artifact. Use a readable monospace hierarchy, real shell syntax and recorded output. Do not fabricate passing tests. Perspective can settle toward front-facing; retain mobile legibility.
- Editorial evidence: source paper → marker behind actual excerpt → text above marker. Name source/date, preserve exact quote, reveal marker after focus settles. For RTL, reveal in the reading direction. Never invent an article, publication or quote.

Research assets from supplied or authoritative sources. Cache URL, local file, license, hash and the claim it supports; unsafe SVG references and scripts must be rejected or sanitized. The original gate hardcoded branded videos, logos and an independent-score rubric; the native evidence utility instead validates local project evidence, hashes source files and rejects stale candidates. Review remains explicit in qa-report.md and cannot be inferred from a high score. Third-party example videos and logos are deliberately not redistributed without a separate rights audit.

```bash
python3 scripts/evidence.py snapshot PROJECT FILE [FILE ...]
python3 scripts/evidence.py verify PROJECT
```

For transparent overlays specify actual alpha container/pixel format and verify through compositing. Deliver source plus reusable insert, provenance, render settings and representative frames. An automated media pass does not certify broadcast polish or human approval.
