# Production-director update — 0.5.0

The toolkit now has an explicit requirement-driven production flow rather than a flat tool catalog. The model interprets the brief; the deterministic helper validates that interpretation, selects relevant master/scene skills and tracks evidence-backed reviews. The production order puts visual proof and actual narration/timed animatic before full animation, final sound and rendering.

Scope includes provided recordings, no-voice inserts, Anatomy-based structures, character-led styles, real data/geography, native output versus explicit upscale, multiple aspect ratios and an existing renderer. Plans declare limits instead of silently misusing the seeded map, generic phone or 720p cartoon profile. A consistent palette/type/camera/motion grammar belongs to the production; specialists are components, not independent default templates to concatenate.

The helper cannot infer arbitrary prose, authenticate a reviewer, judge scientific accuracy/taste from bytes or guarantee professional quality. The agent must inspect/listen, record genuine criterion observations and act on failures. Human approval remains distinct. No paid API, voice generation or model is invoked by plan/next/review.
