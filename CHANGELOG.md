# Changelog

## 0.5.0 — 2026-11-11

Added a production-director flow: structured brief interpretation, requirement-based master/scene routing, native-format constraints, short visual proofs, measured-narration animatics, evidence-backed review gates and selective resumption. It records quality assessments without claiming an automatic professional score or requiring repeated user permissions. Existing skills, artifact checkpoints and Anatomy/ElevenLabs preferences remain compatible.

## 0.4.0 — 2026-11-10

Adopted six cartoon/template animation skills from artemnovitckii/claude-animation-skills with MIT/OFL attribution and retained rigs, props, textures, templates and sound code. Added a shared portable runtime, reproducible dependencies, explicit measured-audio import, deterministic capture and media QA. Kept all existing skill IDs and Anatomy/ElevenLabs preferences; added neutral aliases and bundled the same workflows for ChatGPT.

## 0.3.0 — 2026-11-10

Bundled the supplied MIT Anatomy 0.4 adaptation with its pinned drawing kit, examples and references; future structured diagrams route through it; new production narration uses ElevenLabs. Added persistent project preferences, dependency preflight, a continuous-speech/timestamp helper, content-addressed response reuse and provider-timing review. Existing calibration films remain reproducible; no live external integration is claimed without real access.

## 0.2.0 — 2026-11-09

Adopted nine canonical Codex skills; preserved and adapted upstream utilities with pinned provenance and MIT notices. Added frame-based schemas, measured narration import, resumable checkpoints, caption and asset validation, audio mixing, deterministic browser rendering, evidence hashing, safe symlink lifecycle, standalone ChatGPT packaging, regression tests and reproducible narrated Remotion demos.
